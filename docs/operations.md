# 运行与维护

## 进程和迁移

- 依赖安装沿用 `pnpm install`，新增依赖使用 `pnpm add`；已加入 `@earendil-works/pi-ai`、`@earendil-works/pi-agent-core` 1.6.x，已接入右侧统一对话、服务端工具和流式事件。两包要求 Node.js >=22.19.0，本地当前 Node.js 24.18.0。`lucide-react` 已升级至 1.x，满足 `@lobehub/icons` 的 peer 版本要求；pnpm 和现存 npm 锁文件同步更新。
- `pnpm-workspace.yaml` 显式允许 `protobufjs` 的版本检查安装脚本，禁用 `@google/genai` 的空操作安装脚本；不全局跳过 peer 校验或放开所有依赖脚本。

- 本地：`pnpm dev:all` 同时启动 Next.js 和工作进程；也可分别运行 `pnpm dev`、`pnpm worker`。
- 生产：先执行 `pnpm db:migrate` 和 `pnpm build`，再由进程管理器分别启动 `pnpm start` 和 `pnpm worker`，确保工作进程自动重启。
- 认证表由 Better Auth 生成，SQL 保存为 `db/migrations/000-auth.generated.sql`；业务表使用 `001-canvas.sql`，执行记录存 `ac_migrations`。迁移命令可重复运行，不删除业务数据。
- 业务表以 `ac_` 为前缀。认证用户 ID 使用 UUID，业务表所有者外键采用相同类型。
- 工作进程通过数据库咨询锁避免重复启动，并通过任务租约防止重复领取。测试持有同一锁时不能启动真实工作进程。

## 配置和账号

- 账号开放自主注册，成功后自动登录，无需邮件验证即可创作。SMTP 只用于找回密码，未配置时单独提示该功能不可用，不阻止注册、登录或生成。
- 不提供默认管理员或固定密码。集成测试临时账号仅用于自动验证并会清理。
- `BETTER_AUTH_SECRET` 已在本地 `.env` 安全生成，不写入代码和日志；生产需另设高熵密钥。
- S3 沿用 `S3_ACCESS_KEY`、`S3_SECRET_KEY`、`S3_BUCKET`、`S3_ENDPOINT`、`S3_REGION`。数据库 CA 从 `DB_CA_CERT` 路径读取并启用证书校验。

## 任务异常

- 工作进程离线时，任务保留在 PostgreSQL，启动后恢复。页面中的离线提示不代表任务失败。
- `failed` 表示已知失败，可以显式重新生成；它会创建新的供应商任务，可能重新计费。
- `submission_unknown` 表示提交可能已被受理但未取得可靠回执，不自动重试。维护人员应先在 ToAPIs 控制台核对：找到任务则将其 `provider_id` 写回、状态设为 `queued` 并清空租约；确认未受理才改为 `failed`。核对前不要直接再次发送。
- `saving` 表示供应商结果已返回，正在转存 S3。保存失败只重试下载与转存，不重新生成。
- 首版内部只发送单张生成请求；客户端不能通过修改参数绕过限制。每个项目最多一个进行中任务，每个用户最多两个进行中项目，并有写入、上传和生成频率限制；这些不是收费或长期额度策略。
- 如日志提示图片来源主机未授权，核实供应商真实图片 CDN 后将准确主机加入 `TOAPIS_IMAGE_HOSTS`，不要配置任意通配来源。
- 生成超过 15 分钟可视为耗时较长，不直接当成失败或重复提交。轮询网络失败会退避重试，供应商明确失败才进入失败状态。

## 自动测试与实际验证范围

错误原因映射与 worker 失败落库可独立验证：`node --conditions=react-server --import tsx --test tests/provider-errors.ts`。该测试模拟供应商及数据库，不读取真实凭据，不发起付费请求，覆盖内容审核、账户额度、认证、模型权限、限流、参数错误、未知原因兜底及受理未知保护。

`pnpm test:integration` 需要已启动网页服务、可用数据库和 S3，以及本机 Chrome。先停止工作进程；测试会创建、删除临时账号、项目和 S3 对象。供应商创建、查询及图片返回在测试进程内模拟，真实 ToAPIs 生成不会被调用。

覆盖登录、未登录拒绝、跨用户隔离、来源校验、真实 S3 上传/签名读取、任务幂等、并发、结果转存、画布版本冲突、模型切换、参考图复用、面板宽度、刷新和移动端。未知受理状态不会被再次自动提交。

`pnpm test:registration` 另外覆盖真实浏览器注册后自动登录、新建空项目、上传和移除参考图、空画布选图提示、非法项目 ID 的 404 界面、退出与再次登录。该测试无需停止工作进程，因为不提交生成请求。

该浏览器测试也验证失败占位的按钮、Delete / Backspace 删除、删除失败保留节点、刷新后不恢复、保留生成记录、输入框按键隔离及节点状态和跨用户权限限制。任务与节点均使用测试账号下的临时数据，不调用真实生图。

图片放大预览覆盖画布按钮、双击和对话结果入口、缩放、原始尺寸、适应窗口、拖动查看、Esc 与按钮关闭，以及手机宽度下的布局；复用测试上传图片，不发起生图请求。

画布图片四角缩放验证四个角分别放大/缩小、保持比例、跨轮询周期拖动不回弹、尺寸与位置保存后刷新恢复，以及非法尺寸参数拒绝。

本次已通过 ToAPIs `/v1/models` 只读检查，账号可见 GPT Image2 与 Nano Banana 2.1；这不等于已验证付费生成质量、耗时或费用。正式生成仍需在实际使用中确认，不伪造成已完成的端到端供应商验证。
