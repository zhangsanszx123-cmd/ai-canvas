# 项目需求文档

## 项目背景

项目起始于 Next.js + Supabase 模板，目标是多用户画布生图产品。最新已确认：账号和业务数据均存 PostgreSQL，采用独立认证库，图片使用现有 S3 兼容存储。技术方案选用 Better Auth，后续替换原 Supabase Auth；其他开发沿用现有目录和代码风格。

## 已确认需求与决策

### 数据库连接

- 使用项目根目录 `.env` 中的 `DATABASE_URL` 连接 PostgreSQL 数据库。
- 将连接能力接入项目代码，供服务端业务使用。
- 不公开或提交数据库连接凭据。

- 相关项目文档统一存放在 `/docs/`。
- 本文件存放项目需求、功能规格和已确认的产品决策。

#### Nano Banana 生图服务约定

- 已确认使用 ToAPIs 的 Standard 模型 `gemini-nano-banana-2.1`，详见 [Nano Banana 2.1 接口约定](api/nano-banana-2.1.md)。
- 与 GPT Image2 共用创建任务路径、服务端 ToAPIs 密钥及异步任务管理，分别构建模型请求参数。
- 分辨率传 `metadata.resolution`，取值为大写 `1K`、`2K`、`4K`；参考图传 `image_urls`，禁止 base64。
- `n` 必须为数字 `1`，固定单张生成，不以并行多次调用冒充一次多图请求。
- 单张参考图最大 10MB。统一上传和画布选图按 10,000,000 字节、PNG/JPEG/WebP 校验，产品仍限制一张参考图。

#### GPT Image2 生图服务约定

- 使用用户提供的 ToAPIs GPT Image2 接口说明作为接入依据，模型标识为 `gpt-image-2`；详细规范见 [GPT Image2 接口约定](api/gpt-image-2.md)。
- 通过服务端调用 `POST /v1/images/generations` 创建异步任务；接口 Key 仅供服务端使用。
- 文档提供 `https://toapis.com`，并要求中国大陆使用 `https://toapis.cn`；部署时按环境配置 Base URL。
- 提示词对应 `prompt`，生成数量对应 `n`，尺寸预设拆分为 `size`（比例）和 `resolution`（`1k`、`2k`、`4k`）。例如 `16:9(2k)` 对应 `size=16:9`、`resolution=2k`。
- 参考图以 URL 形式通过 `reference_images` 传入，不传 base64。供应商虽支持最多 14 张，产品仍保持最多一张参考图的约定。
- 接口支持纯文生图和参考图生图，产品允许纯提示词发送。
- 创建接口返回任务 ID，状态包括 `queued`、`in_progress`、`completed`、`failed`；生成中和完成展示需结合任务状态及结果地址更新。
- 本次接口材料未定义质量和自定义宽高参数，也未说明生成数量上限，按下方审查决策限制，不冒充已支持。
- 任务查询接口和结果结构已通过官方文档补全，详见接口文档；透明背景尚未纳入产品功能。

#### 参考图来源与上传

- 点击输入区域的“参考图”入口，展示来源菜单，包含“从本地上传图片”和“从画布选择”，样式参考 `canvas-upload.png`。
- 选择“从本地上传图片”后，可选择本地图片，图片需要上传到存储 bucket，上传成功后以存储服务返回的图片地址作为参考图地址。
- 选择“从画布选择”后，可选用画布中的图片，直接使用该图片已有的远程地址作为参考图地址，无需重复上传到 bucket。
- 输入区域最多添加 **一张参考图**，本地上传和从画布选择共用该限制，不因来源不同而增加数量。
- 添加成功后，在输入区域上方展示参考图缩略图，提示词显示在其下方，底部保留模型、配置摘要和发送入口，样式参考 `canvas-uploaded.png`。
- 参考图和提示词可同时用于生成；允许无参考图发送，提示词必填。已有图片时再次选择会替换，也可移除。
- 已确认使用现有 S3 兼容存储，默认私有 bucket，以签名地址供预览和模型读取，配置从 `.env` 读取。

## 需求审查后的实现决策

以下为用户授权开发者直接确定的默认方案，与用户明确确认的方向分开记录。前文参考图说明中仍提到的“待确认”细节，如在本节已有决策，以本节为准；供应商未证明支持的能力不冒充已接入功能。

### 用户已确认的方向

- 面向多用户；账号和业务数据都存 PostgreSQL，采用独立认证库。
- 图片使用现有 S3 兼容存储，配置从 `.env` 读取。
- 首版开放自主注册，采用邮箱密码认证，账号与会话存 PostgreSQL。
- 注册成功后自动建立会话并进入 `/protected`，无需邮件验证，不因 `emailVerified=false` 限制项目、上传或生图权限。
- Nano Banana 使用 ToAPIs 的 `gemini-nano-banana-2.1`，ToAPIs API Key 已配置到 `.env`。
- 核心是提示词、可选单张参考图生成图片，在可保存的画布及右侧对话中展示结果。

### 项目与输入规则

- “新建项目”创建空项目。首页发送在服务端创建项目、绑定图片并持久化首条任务，再跳转画布；跳转后不重复发送，失败保留输入。
- 默认项目名为提示词前 20 个字符，无提示词时为“未命名项目”；左上角支持重命名。首版品牌使用 AI Canvas。
- 首页显示最近 4 个已有项目，按更新时间倒序；点击任一卡片进入对应画布。全部项目页只展示当前用户项目，按更新时间和 ID 倒序，每次 20 条，游标分页持续加载。
- 封面使用最新成功生成的第一张图片，无图显示灰色占位。读取或轮询不改变项目排序时间，内容修改才更新。
- 首页和画布统一最多一张参考图。提示词去除首尾空白后必填，GPT Image2 最多 32,000 字符；允许纯文生图，不允许仅图无提示词提交。
- 上传 PNG、JPEG、WebP，最大 10MB（10,000,000 字节）。允许替换和移除，替换失败保留原图，上传中禁止发送。
- 从画布选择时进入选择状态，只选当前项目图片，可按 Esc 取消；无图片时提示暂无可选图片。

### 模型与配置规则

- 默认 GPT Image2，初始 `1k`、`1:1`、1 张。Nano Banana 使用已确认的 2.1 模型，初始 `1K`、`1:1`、固定 1 张。未完成真实接入时显示不可生成，不提供假结果。
- 切换模型保留各自配置；选择配置立即更新摘要并保存项目，点击外部或 Esc 关闭浮层。
- GPT Image2 摘要为“比例 · 分辨率 · 张数”，例如 `16:9 · 2K · 1张`；Nano Banana 摘要为“分辨率 · 比例”。
- GPT Image2 质量缺少接口映射：首版标明不可配置；宽高只读显示预设参考值，不提交无映射的自由像素值，不用分辨率替代质量。
- 图片比例与 `1K`、`2K`、`4K` 分辨率独立选择，提交时分别映射为 `size` 和 `resolution`；默认仍为 `1:1`、`1k`。`auto` 由接口决定比例，不承诺固定像素值。
- GPT Image2 的 1–10 张保留为产品目标，上限未验证前只启用 1 张；Nano Banana 明确固定 1 张。其他数量不静默降级，也不自动拆单。
- 透明背景、额外比例和新模型版本不自动纳入首版范围。

### 画布、对话与状态规则

- 同项目最多一个进行中的生成任务，前后端防重复提交；生成中可编辑下一条草稿，不能重复发送。
- 成功受理后清空发送区，保存该次提示词、参考图和参数快照。失败保留错误记录与可恢复输入，刷新后继续读取已存任务。
- 每张结果一个节点，同任务横向排列，新任务排在已有内容下方，间距 32 个画布单位。首批结果适配视口，后续不强制打断用户缩放。
- 画布提供平移、缩放、图片拖动、选择及适配视口。点击对话结果定位对应节点，画布图片可设为下一次参考图。
- 选中画布图片后，四个角显示拖动控制点，可等比例放大或缩小图片在画布中的展示尺寸；调整结束自动保存尺寸及位置，刷新后恢复。仅改变展示大小，不修改原图像素或重新生图；无图片的生成占位不提供缩放控制点。
- 图片支持放大预览：选中画布图片后点击放大按钮或双击图片，对话结果的“查看大图”使用同一预览。预览提供放大、缩小、原始尺寸、适应窗口、拖动查看及下载；支持 + / - 缩放、0 适应窗口、Esc 或关闭按钮退出。预览不修改画布节点尺寸、位置或视口。
- 位置、视口和配置自动保存，操作结束后防抖写入；版本号处理多标签页冲突，失败时明确提示未保存。
- 已明确失败且无图片资源的画布占位支持删除：选中后点击删除按钮，或在画布中按 Delete / Backspace 删除选中的失败占位。删除持久化，刷新后不恢复；右侧生成记录保留。输入区域内按键不触发画布删除。生成中、受理未知和成功图片不在本次删除范围。
- 生成结果转存 S3，以资源 ID 和对象 key 持久化，过期签名 URL 重新获取。转存失败只重试保存，不重新生成。
- 数量不足时保留成功图片并提示，不自动补单。已明确失败的任务可由用户重试，受理未知时不自动重新提交付费请求。
- 结果操作首版提供设为参考图、下载及显式重新生成。评价、分享及未定义工具暂不实现，不显示虚假的可用按钮。
- 对话按多轮独立生成记录组织，默认不自动拼接全部历史消息为提示词。
- 缺少 `projectId` 返回项目列表，不存在或无权访问统一展示 404 并提供返回入口。
- 右侧面板初始 360px，拖动范围保持 320–620px，宽度在当前浏览器记忆；窄屏采用画布/对话标签切换，避免压缩到 320px 以下。
- 空列表、加载、上传失败、生成失败和网络重试均提供明确文字反馈；项目标题旁列表切换图标首版不启用。
- 生图失败按供应商可识别的原因展示中文提示，包括内容安全审核、余额或额度不足、认证失败、模型权限、限流和参数错误；未知原因使用通用提示，不推断为提示词或账户问题。供应商原始错误不直接展示，避免暴露内部信息。提交失败与异步生成失败共用原因映射；受理未知仍禁止自动重新提交。
